# เกมคำชนคำ

[เปิดเกมบน GitHub Pages](https://eizing02.github.io/Thai-kum-prasom/)

**สร้างโดย ครูจันทร์เพ็ญ สังข์วงค์**

สาขาวิชาภาษาไทย มหาวิทยาลัยราชภัฏเลย

เกมภาษาไทยสำหรับนักเรียน ม.1 ฝึกจับคู่คำประสมและคำซ้อนตามแนวตัวชี้วัด ท 4.1 ม.1/2 ของ สพฐ. เล่นด้วยเมาส์ สัมผัส คีย์บอร์ด หรือบีบนิ้วผ่านกล้อง

## เปิดบน Windows

ใช้ Node.js 22.12 ขึ้นไป โครงการตรวจด้วย Node.js 24 จาก PowerShell ในโฟลเดอร์นี้

```powershell
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง โดยปกติคือ http://localhost:5173 กด **เริ่มเล่น** เลือกหัวข้อ ระดับและการควบคุม แล้วเข้าสนาม การติดตั้งจาก package.json ใช้ `npm install` ได้เช่นกัน

## เล่นและตรวจกล้อง

1. ระดับง่ายให้ลากการ์ดตัวเลือกขึ้นแท่นม่วง ระดับปานกลางและยากให้ลากส่วนท้ายไปวางบนส่วนหน้าของคำ
2. ใช้คีย์บอร์ดโดยกด Tab ไปยังส่วนท้าย กด Enter เพื่อหยิบ แล้ว Tab และ Enter บนส่วนหน้า
3. ในโหมดฝึก อ่านเหตุผลหลังตอบถูก กดคำใบ้ได้หลังวางพลาดสองครั้ง โหมดทดสอบแสดงคำอธิบายหลังจบเกม
4. ถ้าใช้กล้อง ให้เลือกกล้องในหน้าเลือกบทเรียน แล้วกด **อนุญาตและเปิดกล้อง** ในหน้าปรับเทียบ บีบนิ้วโป้งกับนิ้วชี้เหนือบล็อก ลากและคลายเหนือช่องวาง ใช้พื้นที่โล่งและเปิดไฟด้านหน้า
5. กด **เข้าสนามพร้อมกล้อง** สนามใช้พื้นที่ทั้งหน้าต่างและจัดการ์ดตามภาพกล้องที่รักษาสัดส่วนเดิม เล็งด้วยปลายนิ้วชี้ แล้วบีบ ลากและคลายเหนือเป้าหมาย กด **ปิดกล้อง** เพื่อใช้เมาส์ต่อในรอบเดิม
6. หน้า **ตรวจสอบการควบคุม** ที่ท้ายเว็บแสดงข้อมูลกล้องและมีปุ่ม **จำลองท่าบีบ** ใช้เมาส์หรือปุ่มลูกศรเพื่อเลื่อน และคลิกหรือกด Space เพื่อบีบหรือคลาย

กล้องใช้ได้ที่ localhost หรือ HTTPS เบราว์เซอร์โหลด WASM และโมเดลจาก URL สาธารณะตามเวอร์ชันที่ระบุ เฟรมกล้องประมวลผลบนอุปกรณ์ ปิดการขอไมโครโฟน การตั้งค่า รอบที่เล่นค้างและผลล่าสุดจะบันทึกเมื่อเปิดตัวเลือกในหน้าตั้งค่า เกมที่เปิดจาก **เล่นรอบเดิมต่อ** จะใช้เมาส์หรือสัมผัส

## ตรวจและสร้างเวอร์ชันเผยแพร่

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

สำหรับทดสอบเพิ่มด้วย MediaPipe จริงและกล้องจำลองของ Chromium (ต้องต่ออินเทอร์เน็ต)

```powershell
$env:TWM_TEST_MODEL = '1'
npm run test:e2e
Remove-Item Env:TWM_TEST_MODEL
```

โฟลเดอร์ `dist` พร้อมสำหรับโฮสต์แบบ static มีตัวอย่างวิธีตั้งค่า Netlify, Vercel และ GitHub Pages ในคู่มือเผยแพร่
