# แผนพัฒนา

1. ตั้ง Vite, React, TypeScript strict, Tailwind, เส้นทางและชุดตรวจคุณภาพ
2. สร้างคลังคำและกติกาที่ทดสอบแยกได้ เชื่อมเกมเมาส์ สัมผัส คีย์บอร์ด ฉาก ผล และคลังคำครู
3. เพิ่มกล้อง MediaPipe ระบบกรอง ท่าบีบมือ หน้าปรับเทียบ และวัดประสิทธิภาพ
4. เชื่อมท่ามือกับระบบหยิบวางเดิม ตรวจ responsive การเข้าถึง เสียงและเอฟเฟกต์
5. ทดสอบครบวงจร ตรวจ Impeccable และส่งมอบคู่มือกับรายงานข้อจำกัด
