# คู่มือครู

## จัดกิจกรรมในคาบ

1. สาธิตคำประสมจากคู่ รถ + ไฟ แล้วชวนอธิบายว่าคำเต็มเรียกสิ่งใด ใช้คู่ ใหญ่ + โต เพื่อเปรียบเทียบการซ้อนคำที่ความหมายใกล้เคียงกัน
2. ให้เริ่มที่โหมดฝึก ระดับง่ายและเมาส์ จากนั้นใช้ระดับปานกลางหรือยากเพื่อจับหลายคู่ในสนามเดียว โหมดทดสอบมีตัวจับเวลาต่อด่านหรือทั้งเกม
3. ให้ผู้เรียนอ่านคำอธิบายแล้วแต่งประโยคใหม่เอง ใช้คำที่พลาด ใช้คำใบ้ หรือทำไม่ทันจากหน้าสรุปสำหรับกิจกรรมทบทวน
4. CSV มีสรุปคะแนน จำนวนครั้งถูกผิด และข้อมูลคำ พิมพ์สรุปจากเบราว์เซอร์ได้ ตารางความแม่นยำคิดจากการวางถูกหารด้วยจำนวนครั้งที่วางถูกและผิด การจับเวลาหมดจะเพิ่มคำที่ยังไม่ได้ตอบไปยังรายการทบทวน

## จัดการคลังคำ

1. เปิด **สำหรับครู** ค้นหาและกด **แก้ไข** หรือลองด้วย **ดูโจทย์**
2. กรอกสองส่วนของคำ ชนิด ระดับ ความหมาย เหตุผล ประโยค และคำใบ้ คั่นตัวหลอกและป้ายกำกับด้วยจุลภาค เลือกภาพประกอบที่เหมาะกับคำ
3. เก็บคำที่ยังตรวจไม่ครบเป็น **รอตรวจทาน** ตรวจการสะกด ความหมาย ชนิดย่อย และประโยคก่อนอนุมัติ ตัวเลือกตรวจลำดับทำให้ต้องลากส่วนท้ายลงบนส่วนหน้า
4. **ส่งออก JSON** ก่อนนำเข้าไฟล์จากอีกเครื่อง นำเข้าทั้งคลังโดยยืนยันการแทนที่ โปรแกรมตรวจข้อมูล คำเต็ม และคู่ที่ซ้ำหรือกำกวม
5. คลังที่ครูแก้ไขเก็บในเบราว์เซอร์บนอุปกรณ์นี้ ใช้ JSON ย้ายหรือสำรองข้อมูล เมื่อใช้เครื่องร่วมกันให้ส่งออกผลตามความจำเป็น แล้วล้างผลล่าสุดและปิดการเก็บรอบที่เล่นค้าง

ชุดตั้งต้น 30 รายการเปิดให้ทดลองเล่น ครูควรตรวจความหมาย ชนิดย่อย ประโยค และคำใบ้ก่อนนำไปประเมินในห้องเรียน
