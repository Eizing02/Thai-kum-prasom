# ระบบกล้องและการตรวจด้วยตนเอง

## ลองใน 5 นาทีบนเครื่องที่จะใช้สอน

1. เปิด Chrome หรือ Edge แล้วเข้า localhost หรือ HTTPS เลือก **กล้อง** ในหน้าบทเรียน
2. กด **อนุญาตและเปิดกล้อง** ยืนยันสิทธิ์ แล้วชูมือในกรอบ เช็กว่าจุดสีเหลืองตามปลายนิ้วทั้งสองและพิกัดไปทางเดียวกับภาพ หากกลับทางให้ลองปิดหรือเปิดการสะท้อนภาพ
3. เล็งลูกบาศก์โดยกางนิ้ว บีบค้างสั้น ๆ ลากไปยังเส้นประ แล้วคลาย ถ้าจับยากให้เพิ่มเกณฑ์หยิบทีละเล็กน้อยและลองอีกครั้ง
4. เข้าสนาม เล็งด้วยปลายนิ้วชี้ บีบ ลากและคลายเหนือคำเป้าหมาย ลองเอามือออกจากกล้องนานกว่าค่ารอที่ตั้งไว้ (เริ่มต้น 400 ms) การ์ดควรค้างในช่วงสั้นและคืนที่เดิมเมื่อหายนานโดยไม่มีคะแนนผิด
5. พัก สลับแท็บ กลับมาเล่น ปิดกล้อง และออกจากเกม ตรวจว่าไฟกล้องดับตอนพักหรือออก ลองปฏิเสธสิทธิ์หนึ่งครั้งและเล่นต่อด้วยเมาส์

## การประมวลผล

- เริ่มหนึ่งมือจาก 21 จุด ระยะนิ้วเทียบขนาดฝ่ามือและสัดส่วนเฟรม ใช้คะแนนการจำแนกซ้าย/ขวาที่ MediaPipe ส่งให้ร่วมกับการตรวจขนาดมือ ค่าเริ่มบีบ 0.30 และคลาย 0.45 ต้องผ่านทั้งเงื่อนไขเวลาและเฟรม
- One Euro Filter กรองพิกัดปลายนิ้วชี้และระยะบีบ การ์ดกับจุดเล็งใช้พิกัดเดียวกันในเฟรมวาดเดียว เมื่อระยะนิ้วเริ่มเกินเกณฑ์คลาย ระบบตรึงจุดวางไว้และรอยืนยันต่อเนื่องอย่างน้อย 85 ms ถ้าบีบกลับจะลากต่อ หากมือเพิ่งกลับเข้าภาพในท่าคลาย ระบบคืนการ์ดเมื่อยืนยันได้และไม่คิดคะแนนผิด
- ผลตรวจที่มาช้าจะคงสถานะการถือไว้ชั่วคราว เมื่อไม่มีผลตรวจนานกว่า 1.1 วินาทีจึงยกเลิกการถือ การคืนการ์ดจากมือหายหรือกล้องค้างไม่ถือเป็นการวางผิด
- หน้าปรับเทียบและสนามใช้โปรไฟล์กล้องเดียวกันและเลือก Worker CPU ก่อน ระดับกราฟิกสูงใช้โปรไฟล์กล้องอัตโนมัติในสองหน้านี้ ส่วน Diagnostics ใช้ระดับสูงเพื่อทดลอง Worker GPU ได้ หาก Worker GPU ค้าง ระบบลองเริ่ม Worker CPU ที่ความละเอียดต่ำก่อน
- Worker รับ ImageBitmap ทีละเฟรมและปิดหลังอนุมาน เมื่อประมวลผลเสร็จรับเฟรมใหม่ตามเพดานของโปรไฟล์ การหยุดกล้องยกเลิกเฟรม ปิด track และคืนทรัพยากรของตัวอนุมาน
- Diagnostics แสดง camera/inference/rAF FPS ระยะเวลาอนุมานและจากรับเฟรมถึงจัดการอินพุต แยกเฟรมที่พลาดจากเฟรมที่ตั้งใจข้าม ตัวนับการคลายชั่วคราวเป็นตัวชี้วัดสัญญาณรบกวน อัตราวางโดยไม่ตั้งใจต้องประเมินจากการทดลองผู้เล่นจริง
- เป้าหมายสำหรับห้องเรียนคือพยายามคง 60 FPS และอนุมาน 20–30 Hz บนเครื่องที่ไหว ทดสอบการหยิบอย่างน้อย 20 ครั้งต่ออุปกรณ์และบันทึกจำนวนสำเร็จ กับแยกการวางหลุดที่ไม่ได้ตั้งใจหากทดลองระยะยาว

WASM ใช้แพ็กเกจ MediaPipe Tasks Vision 0.10.32 จาก jsDelivr ขนาดไฟล์ SIMD ประมาณ 11.5 MB โมเดล Hand Landmarker float16 รุ่น 1 จาก Google ประมาณ 7.8 MB โหลดเมื่อตั้งใจเปิดกล้อง แอปไม่ขอเสียงและไม่ส่งเฟรมกล้องออกไป มีเฉพาะคำขอดาวน์โหลดไฟล์โมเดลและไบนารีไปยังผู้ให้บริการภายนอก
