# สถาปัตยกรรม

| ส่วน | ที่อยู่และหน้าที่ |
| --- | --- |
| เส้นทางและสถานะ | `src/app/App.tsx` จัดการ History API และจุดเข้า Home, Setup, Calibration, Play, Result, Teacher, Diagnostics, Help, Settings |
| คลังคำ | `src/content/schema.ts` ใช้ Zod ตรวจไทย การประกอบคำ โหมด ชนิด ประโยค คำซ้ำ และสถานะอนุมัติ `words.ts` ให้ข้อมูลตั้งต้น |
| กติกา | `src/game/engine.ts` สุ่มตาม seed สร้างด่าน ตรวจ whitelist ประมวลผลคะแนนและคำทบทวน |
| สนาม | `Board.tsx` ผูกเมาส์ สัมผัส คีย์บอร์ด และมือกับการเลือก/หยิบ/วาง จัดตำแหน่งผ่าน `boardLayout.ts` |
| ฉาก | `Scene.tsx` เป็นฉาก Orthographic แบบ R3F การ์ด RoundedBox สองชั้นตามพิกัด CSS เดียวกับปุ่ม DOM ใช้ refs กับเฟรมและใช้แกน Z กับความลึกและยกการ์ด |
| กล้อง | `src/tracking` แยก lifecycle, inference, ตัวกรอง, FSM และ UI `public/hand-worker.js` รับเฟรมทีละหนึ่ง |
| ข้อมูลในเครื่อง | `app/storage.ts` เก็บคลังและค่าที่ผู้เล่นเปิดอนุญาต `progress.ts` เก็บภาพสถานะเกมแบบมีรุ่นและตรวจ schema ตอนเปิดกลับ |

ระดับง่ายมีหนึ่งคู่ต่อด่าน ระดับปานกลางและยากจัดได้สูงสุดสามคู่ต่อด่าน ทุกรอบจริงจัดให้ทำได้ครบ 10 คำ ตรวจรูปคำ ตัวลวง คำตอบทางเลือก และเส้นทางหลังใช้การ์ดแต่ละใบก่อนส่งด่านให้ผู้เล่น คลังที่พร้อมเล่นไม่ถึง 10 คำใช้เปิดดูโจทย์ทีละคำได้ในหน้าครู

โหมดฝึกเริ่มที่ 100 แต้มต่อคู่ โบนัสลดตามจำนวนที่ลองผิด (สูงสุด 30) และการใช้คำใบ้ (20) คะแนนที่สะสมไม่ลด การวางนอกเป้าหมายและมือหายจะคืนการ์ดโดยไม่คิดเป็นคำตอบ ระบบล็อกการคิดคะแนนระหว่างเอฟเฟกต์ ปุ่มคีย์บอร์ดและ drag ผ่านกติกาเดียวกัน

สนามเมาส์ใช้ตำแหน่ง DOM ตามจุดฉาย Orthographic และใช้ CSS สำรองเมื่อ WebGL2 เปิดไม่ได้ สนามกล้องใช้ CSS และจัดพื้นที่การ์ดกับภาพวิดีโอให้อยู่ในกรอบเดียวกันตามสัดส่วนจริง เพิ่มเฟรมแอนิเมชันเมื่อมีการขยับหรือต้องแสดงผลการวาง ส่วนคำอธิบายใช้ข้อความ DOM และฟอนต์ Noto Sans Thai ที่มากับแอป
